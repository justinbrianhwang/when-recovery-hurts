\section{Controller constants, decisions and hand-back}\label{sec:s-constants}

\paragraph{Implementation} The controller is \path{vision_center_v2} in \path{src/hci/vision_center_v2.py}; the trigger rule, the per-step action and the move bounds come from \path{src/hci/recovery_v1_oracle.py} (\path{trigger_rule}, \path{_xy_action}), and the ablation arms from \path{src/hci/vision_center_c1.py}. At the trigger, \texttt{decide} returns ACT or one abstention reason. Abstaining returns without touching the runtime; every run checked that the simulator state, queue, history and counters of an abstaining branch equal those at the trigger. Acting calls \path{policy.clear()} (the pending open command is discarded), sends \path{_xy_action} at each step (horizontal command scaled to the controller's action range, vertical command 0, gripper component equal to the last executed command, which is a close command), re-reads both cameras and re-estimates the offset after each step, and calls \path{policy.clear()} again at the end. Every run checked that no policy inference happened during the move and that the queue was empty at the hand-back.

\paragraph{Order of the rules} \texttt{decide} applies, in this order: an invalid estimate (no held-cube estimate, no target estimate, memory contradicted); \textsc{low carry} (held cube centre below 58\,mm, or a remembered target with the held cube's bottom below the target's top); \textsc{side-contact risk}; \textsc{too few steps}; \textsc{aligned} ($<15$\,mm); \textsc{aligned within uncertainty} (offset $-\,u<10$\,mm); otherwise ACT. The rules-off ablation (\path{decide_rules_off}) removes \textsc{aligned within uncertainty}, \textsc{side-contact risk} and the remembered-target part of \textsc{low carry}, and keeps the rest.

\paragraph{Hand-back as executed} Table~S4 summarises every acted V2 branch. In all of them the policy re-inferred at the first step after the move; its first gripper-open command followed 1--24 steps later, and in one calibration branch it never opened the gripper again. The net horizontal TCP displacement was about 36\% of the commanded path. No move ended at the 30\,mm cap.
